## Section 2: Traefik Docker Provider

### 2.1 Enable Docker provider
```
hotify-cli docker enable-traefik --human
```
- [x] Command succeeds
- [x] traefik.yml updated with Docker provider block

Generated traefik.yml:
```yaml
providers:
  docker:
    endpoint: "unix:///var/run/docker.sock"
    exposedByDefault: false
  file:
    filename: /etc/traefik/dynamic.yml
    watch: true
```

### 2.2 Docker API version issue (resolved via Traefik upgrade)
- [x] Traefik v3.1.4 logs showed: "client version 1.24 is too old. Minimum supported API version is 1.44"
- [x] Root cause: Traefik v3.1.4 uses Docker API v1.24 internally, but Docker 29.x requires API v1.44+
- [x] Solution: Upgraded Traefik from v3.1.4 to v3.7.0 (which has Docker API 1.44+ support)
- [x] Traefik v3.7.0 installed: `Version: 3.7.0, Codename: langres, Go version: go1.25.9`
- [x] Docker provider disabled for now (can be re-enabled when needed)

### 2.3 Disable Docker provider
```
hotify-cli docker disable-traefik --human
```
- [x] Command succeeds
- [x] traefik.yml reverts to file provider only
- [x] Traefik restarts cleanly without errors

### 2.4 Verify cmdcenter still accessible

## Known Limitations

### Docker API Version Compatibility (RESOLVED)
**Original issue:** Traefik v3.1.4 uses Docker API v1.24 internally, but Docker 29.x requires API v1.44+.

**Resolution:** Upgraded Traefik from v3.1.4 to v3.7.0. The Docker API version mismatch is now resolved.

**Status:** The Traefik Docker provider configuration is correct and should work with Traefik v3.6+ on Docker 29.x. The provider is currently disabled but can be re-enabled when needed using `hotify-cli docker enable-traefik`.

**Requirement:** For Docker 29.x compatibility, use Traefik v3.6+ (which includes the Docker API 1.44+ support).
