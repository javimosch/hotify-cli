## Known Limitations

### Docker API Version Compatibility
The Traefik Docker provider requires Docker API version 1.44+.
On dk1, the Docker daemon is running API version 1.24, which is too old.

**Workaround:** Upgrade Docker daemon to a newer version (API 1.44+)
**Impact:** The Docker container management commands work fine via the Docker CLI. Only the Traefik Docker provider integration is affected.

**Status:** This is a platform/environment limitation, not a hotify-cli bug. The configuration generated by hotify-cli is correct.
