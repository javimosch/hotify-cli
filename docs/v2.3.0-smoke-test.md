## Issues Found and Fixed During Testing

1. **Permission denied on traefik.service write** — `setupTraefikService()` now skips writing the service file if it already exists (file is owned by root; config files in `/etc/traefik/` are owned by the deploy user).

2. **Base domain extraction bug** — `getZoneID()` was extracting only the TLD (`fr`) due to finding the last `.` in the string. Fixed to split on all dots and take the last 2 parts (`intrane.fr`).
