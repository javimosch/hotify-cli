June 2026

🛡️

Atomic Config Management

v2.10.1 introduces debounced writes, mutex-protected config, and crash-safe atomic file operations. This prevents race conditions that could silently drop configuration fields (like BackendURL) and eliminates Traefik watch reloads of partially-written files. All config changes are now grouped within a 5-second window and flushed atomically.

🌐

Complete Remote/Targets Support

All hotify-cli commands now support full remote execution via --target flag and local execution via --local flag. This includes deployment commands, app configuration management, Docker operations, pruning, and Docker Compose passthrough — achieving complete SSH independence.
